## Правила реализации

- Делать реальные изменения в `INFEND/QR-LINK` ветка `main`; не ломать передачу, SAF и работу ранее реализованного проводника.
- **ПОСЛЕДНЕЕ ПРАВИЛО 01.11.2026:** с версии **0.3.85 минимальное количество исправлений на релиз отменено полностью**. Разрешена публикация при наличии хотя бы одной реальной завершённой правки в Android-коде, подтверждённой уникальной строкой diff относительно прошлого релиза. Исторические релизы не пересматриваются. Для каждого нового релиза обязательны успешные регрессионные тесты, Android CI, прежний сертификат подписи, update.json, подписанный APK и полный честный русский changelog. Сохранять весь накопительный список требований; отдельное завершение одной из 11 приоритетных задач более не является условием для короткого релиза. Не выпускать пустые версии или фиктивные исправления.
- Для каждой новой задачи проводить регрессионные тесты и проверять на соответствующих сценариях, учитывая Android 11–17 и адаптивные размеры экрана.
- Использовать только статусы «Готово» (реализовано) и «Не готово» (реализация неполная). Проверку на телефонах пользователь проводит самостоятельно. Не заявлять проведённые аппаратные тесты без доказательств.
- В каждом будущем отчёте включать **все** 106 исходных пунктов плюс U01–U32 и последующие запросы, без замены старых новой задачей.

### v0.3.92 · потоковый подсчёт папок SAF

Для папок, разрешённых через системный проводник Android, рекурсивные размеры и количество файлов теперь рассчитываются отдельно от очереди передачи, без ограничения 30000 элементов. Повторные идентификаторы файлов не удваивают сумму; циклы каталогов, противоречивые размеры и отсутствующие размеры не выдаются за точный результат. Если папка выбрана до окончания подсчёта, при превышении лимита очереди используется отдельный обход метаданных. **U02: Не готово** для недоступных SAF-провайдеров и полного снятия ограничений отправки; **F17/F18: Не готово**. Аппаратные испытания не проводились. Тест: `tests/test_folder_card_stats.py`.
