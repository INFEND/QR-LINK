# R07 · Накопительный журнал обновлений

Статус: Готово. Android-код, 286 тестов и release CI SUCCESS; OTA v0.3.111 опубликован. Аппаратных испытаний не проводилось.

При переходе с установленной версии A на B показать в одном прокручиваемом окне все изменения промежуточных релизов (A, B], по versionCode. Пример: 0.3.99 → 0.3.108 включает версии 0.3.100–0.3.108. Не допускать пропусков, дублирования и обрезки текста. Источник истории должен быть доверенным, с корректной обработкой ошибок.

Оформление: [+] жирный зелёный; [=] жирный оранжевый; [–] жирный красный. Важные слова и фразы выделять жирным. Сохранять текущую тему AMOLED и удобную прокрутку.

Тесты: пропущенные и последовательные версии, пустая и повреждённая история, корректное сопоставление версий, дубли, форматирование и полный объём текста.
