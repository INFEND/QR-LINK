QR LINK 0.3.81 · Поиск, проводник и обновления

[+] Сохраняются подтверждения SHA-256 блоков отправки для восстановления передачи.
[=] Поиск обновляет список сразу при вводе без лишней задержки.
[=] Поиск по названию папки показывает также её вложенные файлы.
[=] Повторные записи медиатеки больше не дублируют изображения, видео и музыку.
[=] При открытии медиатеки первой раскрывается папка по алфавиту.
[=] Поиск находит файлы и внутри свёрнутых медиа-папок.
[=] Посторонние файлы медиатеки не расходуют лимит поиска нужного типа.
[=] Некорректные записи системного проводника больше не прерывают открытие папки.
[=] Повторные записи системного проводника больше не дублируют файлы.
[=] Предпросмотр распознаёт формат файла по расширению, когда Android его не сообщает.
[=] Недоступные миниатюры не запрашиваются повторно при каждом обновлении списка.
[=] При недоступности старого адреса обновление загружается с нового адреса.
