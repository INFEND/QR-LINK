QR LINK 0.3.61 · Сохранение OTA после переименования репозитория

[=] Автоматическая сборка поддерживает оба официальных имени одного репозитория: ANTIFERMENT/QR-LINK и INFEND/QR-LINK. Другие репозитории отклоняются.
[+] Для уже установленных версий сохранён исторический адрес загрузки APK: старые клиенты проверяют именно этот путь. GitHub должен перенаправлять его на новый адрес репозитория.
[+] OTA теперь доверяет только двум точным адресам официального репозитория и тегу запрошенной версии; сторонние GitHub-проекты, параметры URL и неподходящие теги отклоняются.
[=] Если прежний адрес OTA-манифеста недоступен, приложение автоматически проверяет второй закреплённый адрес того же репозитория.
[=] Проверка OTA отклоняет некорректные номера версий, пустые или слишком большие файлы и чрезмерно длинные списки изменений.
[=] Генератор OTA больше не создаёт вымышленное описание релиза, если файл release_notes отсутствует: сборка останавливается с ошибкой.
[=] Сообщения об ошибках обновления больше не показывают пользователю сырые англоязычные исключения; добавлены понятные ошибки SSL-сертификатов и запрета незашифрованного соединения.
[+] Исправлен тестовый генератор фиктивного aapt для проверки переименованного репозитория. Добавлены JVM-тесты доверенных URL и регрессионные тесты OTA после переименования, включая отсутствие release_notes.

Подпись APK, applicationId dev.xarkon.link и формат манифеста сохранены. Важно: работоспособность перенаправления старого адреса GitHub на новый в установленном приложении ещё требует проверки на телефонах.
