QR LINK 0.3.57 · Быстрая очередь и поиск по вложенным папкам
[=] Список очереди больше не перечитывает JSON и SQLite каждую секунду без изменений: отдельный поток получает снимок только при изменении очереди, статуса файла или при открытии нового экрана.
[=] Изменения статусов передаются в UI через потокобезопасный монотонный счётчик. Если запись произошла во время загрузки снимка, автоматически запрашивается актуальный снимок.
[=] Для очереди одинаковой длины изменяются только отличающиеся строки адаптера, без clear/add тысяч элементов и потери прокрутки. Полная перестройка нужна только при изменении количества файлов.
[=] Поиск по раскрытым каталогам сохраняет видимыми все родительские папки совпавшего файла. Не относящиеся к результату соседние ветви скрываются.
[+] Добавлены исполняемые JVM-тесты 60000 конкурентных изменений счётчика, поиска в дереве и проверки вынесения дискового чтения с главного потока.
[=] Регрессионный тест интерфейса проводника обновлён: теперь он проверяет поиск с сохранением родительских папок вместо устаревшего удаления всех несовпадающих строк.
[!] Физическая проверка на Samsung S24 Ultra и iQOO ещё нужна: большие очереди, частые завершения маленьких файлов, поиск в глубоко вложенных папках.
[!] applicationId, протокол передачи, постоянный сертификат и адрес OTA не изменены.
