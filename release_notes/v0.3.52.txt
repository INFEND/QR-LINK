QR LINK 0.3.52 · Корень внутренней памяти и безопасный выбор папок
[+] В разделе «Файлы» появился прямой просмотр доступных каталогов из корня общей внутренней памяти /storage/emulated/0 (/0), включая Download, Pictures, DCIM, Documents и другие существующие папки.
[+] Добавлен явный запрос системного разрешения «Доступ ко всем файлам» для Android 11+; приложение не включает его без решения пользователя. При отказе остаётся отдельный доступ через системный SAF.
[=] Папки общей памяти раскрываются прямо в списке, включая вложенные каталоги; кнопка + выбирает папку для передачи со всей вложенной структурой.
[=] Для прямого выбора папок добавлен ограниченный потоковый обход: максимум 12000 файлов и 24 уровня, без перехода по символическим ссылкам и без выхода за пределы общей внутренней памяти.
[=] При возврате из системных настроек разрешений проводник обновляет содержимое без перезапуска.
[=] Предупреждение о неполном списке отображается и для корневого каталога, а не только для SAF.
[!] Разрешение «Доступ ко всем файлам» является специальным доступом Android. Пользователь включает его вручную. Даже с ним Android/data и Android/obb могут быть закрыты системой.
[=] Исправлена регрессионная проверка границ корня хранилища: тест учитывает канонический путь rootPath и не даёт ложных отказов CI.
[!] На S24 Ultra и iQOO проверить выдачу разрешения, открытие /0, выбор вложенных папок, отказ в доступе и отправку файлов через file:// URI. Тесты CI не заменяют проверку на телефонах.
